# Go 1.27 importer compatibility and RC 3

friction: `go test ./...` failed on Go 1.27.1 because `golang.org/x/tools` v0.42.0 could decode export data only through version 2 while the fixture dependency was compiled with export data version 4 -> keep the importer dependency current with supported Go toolchains and exercise both the Go 1.26 floor and Go 1.27 in CI.

decision: per user direction, declare Go 1.27 as the module and fixture minimum, upgrade `golang.org/x/tools` to v0.49.0, and retain the existing cross-package flattening test as the regression proof because it reproduces the real failing importer path.

friction: running full Go 1.26 and Go 1.27 suites concurrently raced over tracked `internal/builder/test_run` outputs and produced misleading nested-module failures -> this repository's full suites must run serially because `TestBasic` rebuilds tracked fixture outputs.

decision: the official Go 1.26 and 1.27 release notes identified three low-risk, directly applicable modernizations: `new(expr)` for marker type IDs, `errors.AsType` for command exit handling, and `slices.Backward` for reverse decoration scanning.

decision: reviewed and accepted the remaining behavior-preserving `go fix -diff ./...` modernizations: Go 1.27 promoted-field composite literals, `maps.Copy`, and removal of a loop-variable capture workaround made obsolete by modern loop semantics.

decision: retain `encoding/json` v1 imports for the 1.0 RC public and generated contract. Go 1.27 implements that API on the faster v2 engine while preserving v1 behavior; direct v2 defaults would additionally change case matching, duplicate-name handling, nil collection encoding, HTML escaping, map ordering, and merge semantics.

doc_bug: the optionality live proof rejected its expected transcript because `expected.json` still listed nullable enums as unsupported after that limitation and its negative fixture had been removed -> remove the stale row and execute the transcript comparison from `go test ./...`.

proof: on Go 1.27.1, `go test -count=1 ./...` passes including `TestFlattenTypes` and the new optionality transcript regression; `go generate ./...`, `JSONSCHEMA_NO_CHANGES=1 go generate ./...`, `go build ./...`, `go vet ./...`, `go fix -diff ./...`, `go run ./internal/cmd/doc-gen --check`, and `git diff --check` pass.

proof: `go run ./gen-jsonschema --help` exercises the real CLI, `go run ./examples/optionality/cmd/proof` now matches its committed transcript, and `npm ci && npm run check` builds all 17 documentation pages with every internal link resolving. The npm audit still reports the pre-existing 1 moderate and 4 high website dependency findings.

release_state: branch `codex/go127-importer-rc3` is ready for its release PR; the intended tag after squash merge is `v1.0.0-rc.3`.
